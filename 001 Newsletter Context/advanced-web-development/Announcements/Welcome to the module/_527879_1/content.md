# Welcome to the module

Published: 2026-09-18T08:00:51.105Z

Hello everyone,

I hope you all had a restful summer break. Welcome back!

This module is designed to take your web development skills to the next level. To succeed, you'll need to be proficient in JavaScript, especially with functions and asynchronous programming concepts (Promise, async and await).

Over the semester, we'll dive into two main topics:

* First, you'll learn to build modern full-stack web applications using the latest version of Next.js and React.
* Then, we'll explore WebAI, exploring TensorFlow.js & Transformers.js to run models directly on the browser.

Our first lecture is scheduled for Tuesday, 22 September, from 14:00 - 16:00 in Data Science and AI Lab (room Sci 0.59). During this session, I will introduce the module, provide details about the first assessment, and then we'll dive in our full stack web development starts with Typescript. Your attendance is important, as we will cover key information.

The lecture will be followed by a practical lab session from 16:00 to 18:00 in the same lab.

All module materials, including weekly lecture slides, lab exercises, and assessment details, will be posted on the Blackboard module page in a timely manner. Please take some time to review these materials before each week's lecture and lab.

If you have any questions, please don't hesitate to reach out to me at j.chin@uea.ac.uk.

We look forward to seeing you all next week!

Jeannette and the Teaching Team
